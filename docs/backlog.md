# Backlog after R1

- **Status:** written 2026-11-24 with the release of R1 (Prompt 8.3), from the open items of CLAUDE.md section 9, which
  were closed or re-filed then. Checks a machine with Docker still owes are not here: they are the rows of
  `docs/runbook.md` section 8. The items 1 to 45 that older documents cite ("CLAUDE.md section 9, item 21") are in
  CLAUDE.md as of commit `4741c7f` (`git show 4741c7f:CLAUDE.md`).

Each row says what is open, of which kind, where it came from, and when it is due:

- **Kind:** an *owner question* waits for a decision; a *recorded deviation* is where the build differs from a document
  and was kept; an *accepted limitation* is known and accepted for R1; a *follow-up* is work to do; a *small fix* is a
  change of a few lines.
- **When:** *R1 review* is for the owner to look at now that R1 is out; R2 to R5 are the releases of CLAUDE.md section
  1; *when touched* is done with the next change to that code or document.

A row is removed when it is done or decided, with its outcome in the change that does it (and an ADR when it changes a
rule).
